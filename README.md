# Assignment #6 — jQuery (Selectors, Effects, Animations)

**Student:** Abylai Duisim  
**Group:** SE-2530  

## Description

This project is a multi-page website demonstrating the use of jQuery. jQuery is loaded using a CDN.

The project covers selectors, DOM manipulation, effects, event handling, and animations.

## Pages

| Page | Tasks |
|---|---|
| `index.html` | Task 0 — Setup, Task 1 — Selectors and CSS |
| `effects.html` | Task 2 — Show/Hide, Task 3 — Fade, Task 4 — Slide |
| `dom.html` | Task 5 — Add/Remove, Task 6 — Attributes, Task 7 — Form |
| `animations.html` | Tasks 8, 9, 10 — Animations |
| `project.html` | Task 11 — Accordion Menu |

The navigation bar on every page is generated dynamically using `common.js`.

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1 (CDN)

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Use the navigation bar to open the other pages.

An internet connection is required to load jQuery from the CDN.
