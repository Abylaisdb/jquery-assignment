Part 5. Mini Project: Accordion Menu

What is jQuery?
jQuery is a JavaScript library that simplifies DOM manipulation, event handling and animations.
Why use selectors?
Selectors let you find elements by ID, class, tag or attribute with short CSS-like syntax.
What are effects?
Effects such as show/hide, fade and slide make interfaces more dynamic with one line of code.
How does .animate() work?
.animate() changes numeric CSS properties gradually over a given time.
